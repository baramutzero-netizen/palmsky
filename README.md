# 이장폐천 (以掌蔽天)

손바닥으로 하늘 가리기. 도트 인크리멘탈 게임입니다.
성적표를 손바닥으로 가리는 것에서 시작해 연습생 데뷔, 스캔들, 입사, 식당, 자녀 실수, 기업 비리, 정치 스캔들, 법정을 거쳐 마지막엔 나 자신까지 가립니다. 아무리 가려도 가린 하늘은 0.001% 언저리입니다.

**바로 플레이:** https://baramutzero-netizen.github.io/palmsky/

`index.html` 파일 하나로 돌아갑니다. 내려받아 브라우저로 열어도 됩니다(그림, 소리, 글꼴이 모두 이 파일 안에 있음).

## 하는 법

- 현장 탭에서 "탁! 가리기"를 누르면(장면을 누르거나 스페이스바를 눌러도 됨) 손바닥을 하나 더 얹습니다. 그때마다 **번 시간(초)**이 쌓입니다. 그래도 손가락 사이로는 다 보이고, 지켜보는 사람들이 한마디씩 합니다.
- 위의 판에는 "가린 하늘 0.000X% · 드러난 하늘 99.999X%"가 나옵니다. 이 숫자는 거의 움직이지 않습니다.
- 가림도 탭의 노드 트리에서 번 시간으로 다음 수를 삽니다. 수는 네 가지입니다.
  - 가리는 수: 시간 배수가 붙습니다.
  - 지켜보는 눈: 사람이 늘어납니다.
  - 대신 가려 주는 손: 자동으로 가립니다.
  - 악단
- 모든 수를 산 뒤 **손 내리기**를 사면 엔딩이 나옵니다. 한 판은 5분 남짓 걸립니다.

## 담긴 것

| 장소 | 가리는 것 | 지켜보는 눈 |
| --- | --- | --- |
| 성적표 | 성적 통지표 | 엄마, 반 친구들 |
| 연습생 데뷔 | 중2 때 올린 SNS 글 | 연습생 동기들, 네티즌 수사대 |
| 스캔들 | 열애설 사진 | 팬들, 파파라치 |
| 입사 | 전체 회신 메일 | 팀원들, 팀장님 |
| 식당 | 주방 | 손님들, 위생 점검원 |
| 자녀 실수 | 학교에서 온 통지 | 학부모들, 선생님들 |
| 기업 비리 | 장부 두 권 | 주주들, 내부 직원들 |
| 정치 스캔들 | 녹취록 | 유권자들, 기자단 |
| 법정 | 증거 제1호 | 방청객, 검사들 |
| 나 자신 | 거울 | 내 안의 목소리, 어린 시절의 나 |

- **악단:** 장소마다 다섯 파트가 있고, 앞 장소의 악단도 같은 볼륨으로 계속 연주합니다(연필 탁탁부터 적막 현악까지 50파트). 파트마다 크기를 재서 고르게 맞췄습니다(`tools/measure_band.js`).
- **엔딩:** 팔이 저려 처음으로 손을 내립니다. 하늘은 처음부터 다 보이고 있었습니다.
- **고백 보고서:** 결과 카드를 PNG로 저장하거나 공유할 수 있고, 다른 게임도 추천합니다.

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 완성된 게임 한 파일 |
| `game.src.html` | 게임 소스(글꼴과 그림이 들어갈 자리가 비어 있음) |
| `assets/aseprite/`, `assets/png/` | 도트 원본 `.aseprite` 파일과 4배 크기 PNG |
| `tools/sprites.py` | 모든 도트의 원본 데이터. `sprites.json`, `.aseprite`, PNG를 만듦 |
| `tools/build.py` | 쓰는 글자만 잘라 글꼴을 넣고 `index.html`을 만듦 |
| `tools/measure_band.js` | 악단 파트별 크기 측정 |

## 다시 빌드하기

```bash
pip install pillow fonttools brotli
cd tools && python3 sprites.py && cd ..
GALMURI=경로/package/dist python3 tools/build.py
```

## 만든 것과 빌린 것

- 도트 그림은 모두 직접 그렸고, 소리는 모두 브라우저에서 실시간으로 합성합니다. 게임 속 인물, 사건, 장소는 모두 지어낸 것입니다.
- 글꼴은 [갈무리(Galmuri)](https://github.com/quiple/galmuri)를 썼습니다(© Lee Minseo, SIL Open Font License 1.1). 게임에 쓰는 글자만 잘라 넣었고, 라이선스 전문은 `fonts/Galmuri-OFL.txt`에 있습니다.
- 진행 기록은 브라우저(localStorage)에만 저장되고 어디로도 보내지 않습니다.
